# Managerial Pitching Research

This directory is for exploratory notebooks about bullpen usage, reliever
workload, rest patterns, pitcher availability, managerial pitching tendencies,
and eventual manager-to-manager comparisons.

Notebooks can be used freely for early exploration. When logic becomes reusable,
move it into `src/crooked_numbers_analytics`, add tests, and import it back into
notebooks rather than maintaining duplicate implementations here.

No managerial pitching analysis has been implemented yet.
